# Security policy

Please report security problems privately, not in a public issue:

- Use GitHub's [private vulnerability reporting](https://github.com/soumyaux/bolo/security/advisories/new), or
- email soumyasahoo473@gmail.com with "Bolo security" in the subject.

Include what you found, how to reproduce it, and the Bolo version (or commit). You will get a reply within a week. Fixes go into the latest version only.

Bolo handles your microphone, keystrokes and clipboard, so reports about data leaving the Mac unexpectedly, keys or dictated text reaching logs or other users, or the installer running untrusted code are especially welcome.
